## Cause and scoped repair

Workspace rules could already materialize exact native contexts and evaluate
their individual invariant bodies. However, granting the existing
`CARTAGO_WORKSPACE_INVENTORY_V1` authority incorrectly depended on a separate
MOISE board-population mapping flag. Auction declares that flag; an independent
workspace-only mapping does not. Consequently, the native aggregate
`OrgContext::CslV4RoleCompatibility` stayed `SKIPPED / POPULATION_UNPROVEN` even
when all body rows passed.

The generic mapping writer now also recognizes current CArtAgO workspace closure
independently of that board policy. It reuses the existing mapped-population
receipt, exact source-cut identities, native engine and MSystem savepoint.
There are no production case/agent names, expected population counts or Goal IDs.

The supported evidence boundaries are:

- A complete stable local source cut explicitly declaring WORKSPACE capture,
  with equal source watermarks and equal valid topology fingerprints.
- A coordinated snapshot with the existing watermark/topology validation policy,
  matching CArtAgO topology fingerprints and the validated versioned capture
  scope/hash. The admitted controller-acquisition profile always enumerates all
  registered workspaces; artifact/property filtering does not filter workspaces.
- Every workspace fact must be faithful, complete and physically unique. The
  existing source decoder validates its UUID, and the existing mapped-population
  receipt reconciles all declared rules and actual native objects at the same cut.

These are current population guarantees. They do not grant continuous history,
unbounded distributed-platform coverage or cross-framework atomicity. No barrier,
operation admission, timer, deadline, authentication or release logic changed.

Missing/partial evidence, unstable watermarks/topology, a wrong capture scope hash,
an omitted capture kind, a dropped mapped object or a retained stale context
cannot borrow the preceding cut's certificate. Savepoint rollback restores the
receipt with its native state. The pre-existing Auction board/agent proof paths
and the invariant predicate itself remain unchanged.
