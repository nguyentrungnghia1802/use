# USE4GOAL_OBSERVED_V1 runtime admission

The original seven marking/propagation sources are unchanged. P-CTX-01 adds only
topology metadata and a public delegate to the existing dependency saturation.
Removing the registered addition reproduces the pinned translator byte content
(after line-ending normalization); its original evaluate methods are unchanged.
An isolated original-source compiler compares the complete old evaluate output
for shared/separate contexts, and the new seam and aggregate result for the same
cast/script. Full binding stacks distinguish standalone and dependency occurrences.

The original core has a 10,000 pass cap and no convergence indicator. This profile
therefore admits only acyclic activation/refinement/dependency graphs, <=4,096
occurrences, <=16,384 definition edges and depth <=256. Refinement parents have no
direct task contract. Derived status possibilities must roundtrip through the
original GoalMarking/TaskMarking.fromStatus. In particular MAINTAIN+PENDING and
ACHIEVE+VIOLATED do not roundtrip; allowing those edges can keep closePending
changing an unrepresentable status until its cap. They are rejected, not patched.
Sufficient contributions have one polarity per quality, an executable Goal/Task
source and no incoming quality-to-Goal feedback. Opposing contributions and
Help/Hurt runtime verdicts are unsupported. Under this admitted DAG each derived
status stabilizes along at most the graph depth; contributions add terminal quality
updates. The existing core cap remains unchanged, above the admitted depth.

Unknown tuple slots never invoke Boolean recurrence. Raw records preserve temporal
fields, independently of status-reconstructed aggregate copies. A caller must gate
certified verdicts using observation quality; retained last-known history alone is
not current evidence. Episodes, reset epoch, cast revision and per-session token
fence savepoints. The neutral adapter owns no MSystem, TCP connection or worker.
